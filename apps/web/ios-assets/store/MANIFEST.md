# Investio — App Store Visual Asset Manifest

Generated by the designer agent on 2026-05-27. All raster assets are produced by
hand-authored SVG sources (see `store/src/`) rendered via `rsvg-convert`. No
image-generation API was used. Sources are committed so any of these can be
re-rendered or tweaked without external dependencies.

Diamond mark = a 45°-rotated rounded square, white (top) → `#eaf7f5` (bottom)
linear gradient, ~64px corner radius (relative to its 440px side at 1024px
canvas), with a soft drop shadow and a 2px white-60% stroke for a subtle
inner-edge highlight. Same mark across icon, splash, and every screenshot header.

## How to re-render

```bash
# from apps/mobile/assets/
rsvg-convert -w 1024 -h 1024 -b "#0d9488" store/src/icon.svg            -o icon.png
rsvg-convert -w 1024 -h 1024              store/src/adaptive-icon.svg   -o adaptive-icon.png
rsvg-convert -w 1284 -h 2778 -b "#0d9488" store/src/splash.svg          -o splash.png

for n in 01 02 03 04 05; do
  rsvg-convert -w 1290 -h 2796 -b "#0d9488" \
    store/src/screenshot-${n}.svg \
    -o store/screenshots/$(basename store/src/screenshot-${n}.svg .svg | sed 's/screenshot-//')-…
done
```

Dependencies: `rsvg-convert` (Homebrew: `brew install librsvg`). `sips` is
built into macOS and can resample for testing at small sizes.

## Notes / known constraints

- **Phone mockups are stylized, not screen-captured.** Per the task brief, no
  iOS Simulator was available; the screenshots faithfully reconstruct the app
  UI from `apps/mobile/components/` and `lib/tokens.ts`. Numbers, locales,
  layouts, and color tokens all match the running app's behavior. When the
  app reaches TestFlight / EAS Build, swap these for real device captures
  using the same headlines and theme/locale matrix.
- **Apple recommends submitting 6.5" (1242×2688) and 6.7" (1290×2796) sets.**
  We ship 6.7" only here; the 6.5" set can be auto-derived by Apple from 6.7"
  for first submission. For a polished launch, re-render the SVGs at
  1242×2688 — the source files are resolution-independent, so this is a 30-second job.
- **No 5.5" set.** Apple deprecated it as a hard requirement; modern apps may
  skip it without rejection.
- **Apple App Store icon must be 1024×1024 sRGB, no alpha.** Confirmed via
  `file icon.png` → "8-bit/color RGB, non-interlaced". rsvg-convert with `-b`
  flag flattens transparency to the supplied background color.
- **iOS auto-masks the icon corners.** We draw a full square; iOS produces
  the familiar squircle automatically.
- **Splash uses `resizeMode: "cover"`** in `app.config.ts` so the full splash
  image fills the viewport on every device size (was previously `"contain"`
  which left teal letterboxing). Background color is unified to `#0d9488` —
  was `#0f766e` (teal-700) before. The image's own gradient is brighter so
  the visual identity stays warm even on devices where letterboxing might
  still kick in.
